# 기능 토글 (F009-02)

## 개요
기능 단위로 활성/비활성을 제어하여 사용자 환경에 맞게 구성

## 하위 기능 목록

### 훅 비활성 (F009-02-01)

원치 않는 자동화 기능을 선택적으로 끔


---

### 에이전트 비활성 (F009-02-02)

사용하지 않을 에이전트를 제외


---

### 스킬 비활성 (F009-02-03)

스킬 목록에서 특정 스킬을 제외


---

### 명령 비활성 (F009-02-04)

단축 명령 중 일부를 비활성화


---

### 외부 연동 비활성 (F009-02-05)

외부 연동 항목을 선택적으로 비활성화


---
