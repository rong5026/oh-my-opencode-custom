# 환경 진단 (F007-04)

## 개요
설치 상태, 설정, 인증, 도구 사용 가능 여부를 점검

## 하위 기능 목록

### 설치 진단 (F007-04-01)

필수 구성요소 설치 상태를 점검


---

### 설정 진단 (F007-04-02)

설정 파일의 유효성과 충돌을 점검


---

### 인증 진단 (F007-04-03)

계정 연결 및 인증 상태를 점검


---

### 도구 진단 (F007-04-04)

개발 도구 및 외부 연동의 동작 가능 여부를 점검


---

### 상세 진단 모드 (F007-04-05)

문제 분석을 위한 상세 정보를 포함해 출력


---

### 카테고리별 진단 실행 (F007-04-06)

특정 진단 영역만 선택해 실행


---
