# 스킬 및 명령 관리 (F004)

## 개요
재사용 가능한 작업 절차(스킬)와 단축 명령을 발견·병합·실행하는 기능

## 하위 기능 목록 (L2)

| ID | 기능명 | 설명 |
|----|--------|------|
| F004-01 | [스킬 탐색 및 로드](./F004-01-스킬-탐색-및-로드.md) | 여러 위치에 있는 스킬 정의를 찾아 사용 가능 상태로 로드 |
| F004-02 | [스킬 병합 및 정책 적용](./F004-02-스킬-병합-및-정책-적용.md) | 내장/사용자/프로젝트/플러그인 스킬을 우선순위로 병합하고 활성 정책을 적용 |
| F004-03 | [내장 스킬 제공](./F004-03-내장-스킬-제공.md) | 기본 제공되는 대표 스킬로 특정 유형 작업을 빠르게 수행 |
| F004-04 | [내장 명령 제공](./F004-04-내장-명령-제공.md) | 반복되는 워크플로우를 단축 명령으로 제공 |
