# 내장 명령 제공 (F004-04)

## 개요
반복되는 워크플로우를 단축 명령으로 제공

## 하위 기능 목록

### 프로젝트 지침 체계화 (F004-04-01)

프로젝트의 지식/지침을 구조화하여 에이전트 이해도를 높임

**상세 기능 (L4):**
- **지식 베이스 초기화** (F004-04-01-01): 프로젝트 전반에 적용될 지침 구조를 구성

---

### 리팩토링 워크플로우 실행 (F004-04-02)

탐색→변경→검증의 단계형 리팩토링 흐름을 수행

**상세 기능 (L4):**
- **리팩토링 단계 체크리스트 생성** (F004-04-02-01): 리팩토링 진행을 단계별로 관리할 수 있게 구성

---

### 반복 작업 루프 실행 (F004-04-03)

완료될 때까지 반복 수행하는 루프형 작업을 시작

**상세 기능 (L4):**
- **루프 중단 명령** (F004-04-03-01): 실행 중인 루프를 사용자가 즉시 중단

---
