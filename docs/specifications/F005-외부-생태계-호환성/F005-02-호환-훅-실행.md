# 호환 훅 실행 (F005-02)

## 개요
사용자 정의 훅을 입력/도구 사용 흐름에 맞춰 실행

## 하위 기능 목록

### 사용자 입력 훅 실행 (F005-02-01)

사용자 메시지 제출 시 커스텀 훅을 실행


---

### 도구 사용 전 훅 실행 (F005-02-02)

도구 실행 전 입력 검증/수정 훅을 실행


---

### 도구 사용 후 훅 실행 (F005-02-03)

도구 실행 후 기록/후처리 훅을 실행


---

### 요약 전 훅 실행 (F005-02-04)

세션 요약 전에 커스텀 훅을 실행


---

### 종료 시 훅 실행 (F005-02-05)

세션 종료/유휴 시 커스텀 훅을 실행

**상세 기능 (L4):**
- **훅 부분 비활성** (F005-02-05-01): 특정 이벤트 유형의 훅만 선택적으로 비활성화

---
