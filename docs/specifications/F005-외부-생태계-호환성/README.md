# 외부 생태계 호환성 (F005)

## 개요
기존 사용자 자산(명령/스킬/에이전트/연동/훅)을 그대로 활용할 수 있게 지원

## 하위 기능 목록 (L2)

| ID | 기능명 | 설명 |
|----|--------|------|
| F005-01 | [호환 자산 로드](./F005-01-호환-자산-로드.md) | 기존 환경의 명령어·스킬·에이전트·연동 설정을 자동으로 불러옴 |
| F005-02 | [호환 훅 실행](./F005-02-호환-훅-실행.md) | 사용자 정의 훅을 입력/도구 사용 흐름에 맞춰 실행 |
| F005-03 | [호환 작업 기록 관리](./F005-03-호환-작업-기록-관리.md) | 기존 환경과 호환되는 형태로 작업 기록과 상태를 유지 |
