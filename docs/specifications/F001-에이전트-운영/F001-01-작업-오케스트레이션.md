# 작업 오케스트레이션 (F001-01)

## 개요
복잡한 작업을 계획하고 적합한 에이전트/도구로 위임하여 병렬로 처리

## 하위 기능 목록

### 작업 계획 수립 (F001-01-01)

사용자 요청을 이해하고 실행 가능한 단계로 나누어 진행 전략을 수립

**상세 기능 (L4):**
- **요청 목표 해석** (F001-01-01-01): 사용자 요청에서 목적과 제약조건을 추출
- **하위 작업 분할** (F001-01-01-02): 큰 작업을 더 작은 실행 단위로 분리
- **우선순위 결정** (F001-01-01-03): 리스크/효과에 따라 작업 순서를 정렬

---

### 전문 역할 위임 (F001-01-02)

전략, 조사, UI, 문서 등 역할별 전문 에이전트에게 업무를 배정

**상세 기능 (L4):**
- **전략 자문 위임** (F001-01-02-01): 설계/디버깅 방향성에 대한 고급 조언을 요청
- **코드베이스 탐색 위임** (F001-01-02-02): 프로젝트 구조·패턴을 빠르게 파악하도록 탐색 작업을 위임
- **외부 자료 조사 위임** (F001-01-02-03): 공식 문서와 공개 예시를 찾아 근거 기반의 해결책을 수집
- **UI/UX 구현 위임** (F001-01-02-04): 프론트엔드 화면·UX 개선 작업을 전문 에이전트에 위임
- **문서 작성 위임** (F001-01-02-05): 사용자 안내/기술 문서를 체계적으로 작성하도록 위임
- **이미지·문서 분석 위임** (F001-01-02-06): 이미지/PDF 등 비정형 자료에서 요구사항을 추출하도록 위임

---

### 에이전트 선택 및 전환 (F001-01-03)

기본 에이전트를 설정하고 상황에 따라 다른 에이전트로 작업을 수행

**상세 기능 (L4):**
- **기본 에이전트 지정** (F001-01-03-01): 기본 실행 에이전트를 지정하여 일관된 작업 방식 유지
- **특정 에이전트로 실행** (F001-01-03-02): 요청 성격에 맞는 에이전트를 명시적으로 선택
