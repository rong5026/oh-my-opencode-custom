# 에이전트 카탈로그 제공 (F001-02)

## 개요
사전 제공되는 다양한 전문 에이전트를 사용할 수 있도록 제공

## 하위 기능 목록

### 총괄 오케스트레이터 (F001-02-01)

전체 작업을 계획하고 전문 에이전트를 조합해 실행을 지휘

**상세 기능 (L4):**
- **다중 에이전트 협업 조율** (F001-02-01-01): 여러 에이전트를 동시에 활용해 조사/구현을 병렬화

---

### 전략·검토 전문가 (F001-02-02)

복잡한 문제의 해결 전략 수립 및 코드 품질 관점의 검토 지원

**상세 기능 (L4):**
- **아키텍처 의사결정 지원** (F001-02-02-01): 설계 대안 비교 및 선택 기준 제시
- **복잡도 높은 디버깅 가이드** (F001-02-02-02): 원인 가설 수립과 검증 순서 제안

---

### 외부 자료 조사 전문가 (F001-02-03)

공식 문서 및 공개 예시를 기반으로 해결책을 조사

**상세 기능 (L4):**
- **공식 문서 기반 조사** (F001-02-03-01): 최신 문서 내용을 바탕으로 사용법/제약을 확인
- **공개 예시 기반 조사** (F001-02-03-02): 실제 사용 사례를 찾아 적용 가능성을 평가

---

### 코드베이스 탐색 전문가 (F001-02-04)

프로젝트 구조와 코드 패턴을 빠르게 파악해 변경 범위를 제안

**상세 기능 (L4):**
- **구조·패턴 식별** (F001-02-04-01): 폴더/모듈별 역할과 반복 패턴을 찾아 요약

---

### UI/UX 구현 전문가 (F001-02-05)

디자인 감각을 바탕으로 사용자 경험 중심의 UI 결과물을 생성


---

### 기술 문서 작성 전문가 (F001-02-06)

명확하고 일관된 문서/가이드를 작성


---

### 이미지·문서 분석 전문가 (F001-02-07)

이미지/PDF 등 시각 자료에서 정보를 추출해 요약


---

### 코드베이스 기능 분석 전문가 (F001-02-08)

코드·문서를 바탕으로 비즈니스 기능을 체계적으로 식별


---

### 기획서 구조화 전문가 (F001-02-09)

기능을 폴더/화면/흐름 구조로 정리


---

### 요구사항 검증 전문가 (F001-02-10)

누락, 중복, 모순을 찾아 수정 제안


---

### E-commerce 기능 분석 전문가 (F001-02-11)

기획 문서를 상세한 계층적 명세로 변환


---

### E-commerce UX 개선 전문가 (F001-02-12)

창의적 개선안과 누락 기능을 제안


---
