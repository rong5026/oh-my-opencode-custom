# 코드 탐색 및 이해 (F002-01)

## 개요
코드 구조와 의미를 빠르게 파악하도록 돕는 기능

## 하위 기능 목록

### 정의/문서 확인 (F002-01-01)

심볼의 타입/설명/사용법 정보를 즉시 확인

**상세 기능 (L4):**
- **시그니처 확인** (F002-01-01-01): 함수/타입의 입력·출력 형태를 확인

---

### 정의로 이동 (F002-01-02)

코드 요소가 정의된 위치로 빠르게 이동


---

### 사용처 찾기 (F002-01-03)

코드 요소가 어디에서 사용되는지 전체 범위에서 탐색


---

### 파일 구조 요약 (F002-01-04)

파일 내 주요 구성요소(함수/클래스 등)를 계층적으로 파악


---

### 전체 심볼 검색 (F002-01-05)

프로젝트 전체에서 이름 기반으로 기능/구성요소를 검색


---

### LSP 서버 상태 확인 (F002-01-06)

사용 가능한 LSP 서버 목록과 설치 상태를 확인


---
