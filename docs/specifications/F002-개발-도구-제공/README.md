## 개요

| ID | 기능명 | 설명 |
|----|--------|------|

| F002-03 | [안전한 대규모 변경](./F002-03-안전한-대규모-변경.md) | 프로젝트 전반에 영향을 주는 변경을 안전하게 수행하는 기능 |
| F002-04 | [구조 기반 검색 및 일괄 변경](./F002-04-구조-기반-검색-및-일괄-변경.md) | 코드의 구조를 기준으로 패턴을 찾아 안전하게 일괄 변경 |

| F002-08 | [이미지·문서 분석](./F002-08-이미지문서-분석.md) | PDF/이미지 등 시각 자료에서 정보를 추출해 작업에 활용 |

| F002-10 | [슬래시 명령 실행](./F002-10-슬래시-명령-실행.md) | 단축 명령으로 복합 워크플로우를 실행 |
