# 외부 워크플로우 호환 훅 (F003-07)

## 개요
외부 생태계의 훅 체계를 동일한 방식으로 실행하도록 지원

## 하위 기능 목록

### 외부 훅 실행 지원 (F003-07-01)

사용자 정의 훅을 입력/도구 실행 흐름에 맞춰 실행

**상세 기능 (L4):**
- **도구 사용 전 훅** (F003-07-01-01): 도구 실행 전에 조건 검증 또는 입력 조정
- **도구 사용 후 훅** (F003-07-01-02): 도구 실행 결과를 후처리하거나 기록
- **사용자 입력 훅** (F003-07-01-03): 사용자 입력 시 메시지 주입/차단 등 정책 적용
- **종료 시 훅** (F003-07-01-04): 세션이 멈출 때 추가 안내/후속 작업을 유도
