# 컨텍스트 자동 주입 (F003-01)

## 개요
작업에 필요한 지침과 문서를 자동으로 제공하여 맥락 손실을 줄임

## 하위 기능 목록

### 디렉토리 지침 주입 (F003-01-01)

작업 위치에 맞는 프로젝트 지침을 자동으로 주입

**상세 기능 (L4):**
- **범위 기반 지침 적용** (F003-01-01-01): 작업 대상 위치에 따라 해당 범위의 지침만 적용

---

### 디렉토리 안내문서 주입 (F003-01-02)

사용 설명/가이드를 자동으로 제공


---

### 규칙 기반 지침 적용 (F003-01-03)

조건에 맞는 규칙 문서를 찾아 자동 적용

**상세 기능 (L4):**
- **중복 주입 방지** (F003-01-03-01): 같은 지침이 반복 삽입되지 않도록 관리

---
