# 워크플로우 자동화 (F003)

## 개요
대화·도구 사용·세션 상태에 반응하여 자동으로 안전장치와 편의 기능을 제공

## 하위 기능 목록 (L2)

| ID | 기능명 | 설명 |
|----|--------|------|
| F003-01 | [컨텍스트 자동 주입](./F003-01-컨텍스트-자동-주입.md) | 작업에 필요한 지침과 문서를 자동으로 제공하여 맥락 손실을 줄임 |
| F003-02 | [작업 지속 및 완료 강제](./F003-02-작업-지속-및-완료-강제.md) | 작업이 중간에 멈추지 않도록 감지·재개·반복 수행을 자동화 |
| F003-03 | [오류 복구 및 안정성](./F003-03-오류-복구-및-안정성.md) | 실패 상황을 감지해 자동 복구하고 무한 재시도를 방지 |
| F003-04 | [컨텍스트 최적화](./F003-04-컨텍스트-최적화.md) | 긴 대화에서도 핵심 맥락을 유지하도록 요약·정리·축약을 자동 수행 |
| F003-05 | [사용자 편의 기능](./F003-05-사용자-편의-기능.md) | 키워드 기반 모드 전환, 자동 실행, 알림 등 사용자 경험을 향상 |
| F003-06 | [환경 호환](./F003-06-환경-호환.md) | 대화형/비대화형 환경 차이를 고려해 기능을 적절히 조정 |
| F003-07 | [외부 워크플로우 호환 훅](./F003-07-외부-워크플로우-호환-훅.md) | 외부 생태계의 훅 체계를 동일한 방식으로 실행하도록 지원 |
