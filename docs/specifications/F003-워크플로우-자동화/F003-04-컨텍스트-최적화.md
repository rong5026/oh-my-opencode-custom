# 컨텍스트 최적화 (F003-04)

## 개요
긴 대화에서도 핵심 맥락을 유지하도록 요약·정리·축약을 자동 수행

## 하위 기능 목록

### 선제 요약 (F003-04-01)

대화가 길어지기 전에 미리 요약하여 중단을 예방

**상세 기능 (L4):**
- **임계치 기반 요약 트리거** (F003-04-01-01): 사용량이 높아지면 자동으로 요약을 수행

---

### 한도 초과 복구 (F003-04-02)

입력 한도 초과로 실패한 경우 단계적으로 정리하여 복구


---

### 도구 출력 축약 (F003-04-03)

과도하게 긴 도구 출력으로 맥락이 낭비되는 것을 방지


---

### 요약 시 핵심 정보 보존 (F003-04-04)

요약 과정에서도 프로젝트 핵심 지침이 사라지지 않도록 보강


---

### 사용량 모니터링 알림 (F003-04-05)

맥락 사용량을 관찰해 에이전트의 작업 전략을 조정하도록 유도


---

### 동적 컨텍스트 정리 (F003-04-06)

중복 도구 호출과 오래된 출력을 제거하여 토큰 절약

**상세 기능 (L4):**
- **중복 도구 호출 제거** (F003-04-06-01): 동일한 도구와 인자로 호출된 중복 기록을 제거
- **오래된 출력 정리** (F003-04-06-02): 이후 읽기로 대체된 쓰기 출력 등을 정리
- **오류 출력 제거** (F003-04-06-03): 일정 턴 이후 오류 도구 입력을 제거

---
