# 사용자 편의 기능 (F003-05)

## 개요
키워드 기반 모드 전환, 자동 실행, 알림 등 사용자 경험을 향상

## 하위 기능 목록

### 키워드 기반 모드 전환 (F003-05-01)

특정 키워드로 탐색/분석/집중 작업 모드를 빠르게 활성화

**상세 기능 (L4):**
- **탐색 모드 트리거** (F003-05-01-01): 대규모 검색/병렬 조사를 강화하는 모드를 유도
- **분석 모드 트리거** (F003-05-01-02): 컨텍스트 수집 후 심층 분석을 수행하도록 유도

---

### 생각 모드 감지 (F003-05-02)

요청 성격에 따라 더 신중한 사고 과정을 유도


---

### 자동 슬래시 명령 실행 (F003-05-03)

대화 중 명령 패턴을 감지해 자동으로 실행


---

### 에이전트 사용 리마인드 (F003-05-04)

상황에 맞는 전문 에이전트를 사용하도록 안내


---

### 세션 알림 (F003-05-05)

세션이 멈추거나 사용자 주의가 필요할 때 알림 제공


---

### 백그라운드 완료 알림 (F003-05-06)

백그라운드 작업 완료 시 사용자에게 알림 제공


---

### 업데이트 알림 (F003-05-07)

새 버전 존재 여부를 확인해 사용자에게 안내

**상세 기능 (L4):**
- **알림 충돌 회피** (F003-05-07-01): 다른 알림 기능과 충돌할 경우 중복 알림을 피하도록 조정

---
