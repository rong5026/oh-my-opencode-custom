# 작업 지속 및 완료 강제 (F003-02)

## 개요
작업이 중간에 멈추지 않도록 감지·재개·반복 수행을 자동화

## 하위 기능 목록

### 할 일 미완료 감지 (F003-02-01)

세션이 멈출 때 미완료 작업이 있는지 확인

**상세 기능 (L4):**
- **자동 재개 프롬프트 주입** (F003-02-01-01): 미완료 작업이 남아 있으면 자동으로 이어서 진행하도록 유도

---

### 반복 실행 루프 (F003-02-02)

완료 신호가 나올 때까지 반복적으로 작업을 계속 수행

**상세 기능 (L4):**
- **완료 신호 감지** (F003-02-02-01): 작업이 완료되었음을 나타내는 명시적 표식을 감지

---

### 반복 실행 중단 (F003-02-03)

사용자 요청으로 반복 실행을 중단
